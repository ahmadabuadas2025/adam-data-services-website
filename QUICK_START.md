# Quick Start Guide

## 🚀 Get Started in 3 Steps

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Development Server
```bash
npm run dev
```

### 3. Open Browser
Navigate to `http://localhost:3000`

That's it! Your premium 3D website is now running.

## 📝 Next Steps

1. **Update Company Data**: Edit `src/data/companyData.js` with your actual company information
2. **Add Partner Logos**: Place logos in `public/partners/` and update `src/sections/Partners.jsx`
3. **Customize Content**: Review all sections and update with real project details
4. **Update Contact Info**: Edit contact details in `src/sections/Contact.jsx`

## 📦 Build for Production

```bash
npm run build
```

The `dist` folder will contain your production-ready website.
